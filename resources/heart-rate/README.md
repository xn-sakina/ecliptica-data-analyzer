# Heart rate setup

1. [Download the latest vrchat-fast-heart release](https://github.com/xn-sakina/vrchat-fast-heart/releases) and open it.
2. Connect your heart-rate source in vrchat-fast-heart.
3. Turn on **Report to other apps**.
4. In Ecliptica Data Analyzer, open **OSC Messages**, enable **Heart rate**, and save the settings.

Keep both apps running. Heart rate is now available in live messages and round reports.
